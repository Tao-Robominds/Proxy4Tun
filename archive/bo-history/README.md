# BO code history (duplicate roots)

Canonical live code: `bo/` (including `bo/sc_general/`, phase packages, README, REPORT).

These directories are frozen snapshots of the pre-consolidation top-level roots
(`bo-elegant`, `bo-full-stage`, `bo-notebook-direct`, `bo-proxy-scale`,
`bo-unified`). They differ slightly from the current `bo/<phase>/` trees and are
kept only for forensic comparison. Do not run campaigns from here.

Artifact data remains under protected `data/bo/` (aliases `data/bo-*`).
