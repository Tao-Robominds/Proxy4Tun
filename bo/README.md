# bo/

Current campaign code for the four-feature proxy and refinement panel.

| Path | Role |
|---|---|
| `sc_general/` | Scripts in use: tables, proxy, selector, campaigns, paper figures |
| `runtime/` | Pipeline, search-space, and Ridge helpers those scripts import |
| `paths.py` | Repository and data-root paths |

Older phase packages (`unified`, `elegant`, `full_stage`, `bayes`, and the rest) are in `releases/1.0/code/`.
